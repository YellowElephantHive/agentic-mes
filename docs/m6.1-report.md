## Implemented

- `scripts/fetch-evaluation-datasets.sh --track a|b|all` downloads only the
  requested pinned UCI archive and fails on a checksum mismatch.
- `scripts/evaluate-track.sh a|b` provides one reproducible download, import,
  and evaluation entry point per track.
- The Rust evaluator accepts `--track a|b|all` while preserving the combined
  default for existing users.
- Track A and Track B run as separate GitHub Actions jobs with independent
  PostgreSQL service containers, dataset downloads, imports, and reports.
- Each job writes its current-run report outside the checked-out `reports/`
  tree, publishes it in the job summary, and uploads it as a separate artifact.
  A previously committed PASS report cannot mask a download or import failure.
- The `M6.1 dual-track gate` runs even after an upstream failure and succeeds
  only when both independent job results are `success`.
- The original one-command MVP reproduction delegates to the two independent
  track entry points and remains backward compatible.
