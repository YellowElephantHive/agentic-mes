## Frozen contract

The binding contract is
[M9 deterministic disposition planning and dry-run contract](m9-action-plan-contract.md).
It defines:

- a typed plan derived only from an independently approved M8 proposal;
- frozen maintenance, quality, and bounded inventory-reconciliation plan and
  step registries;
- deterministic source bindings, preconditions, canonical snapshots, and
  SHA-256 state-drift detection;
- reproducible dry-run isolation with protected-state before/after checks;
- draft, validation, simulation, submission, independent-review, expiry,
  cancellation, drift invalidation, and immutable terminal states;
- M9 capability bundles, tenant/factory scope, resource hiding, and
  creator/reviewer separation of duties;
- idempotency, optimistic concurrency, immutable submitted plans, append-only
  simulation/review/audit history, and sanitized audit requirements;
- 41 mandatory security and regression cases; and
- an explicit prohibition on execution routes, external export, production
  writes, real ticket creation, or autonomous approval.

## Current boundary

M9.0 is a contract-only milestone. No action-plan domain model, migration,
API, validator, snapshot, dry-run, or plan-review runtime is implemented yet.
M8 remains the current executable boundary.

An M9 `plan_approved` record will mean only that a human accepted an
investigation plan. It will not authorize or perform the plan.
