# M10.5 Guided Pilot Contract

Status: **FROZEN FOR M10.5 IMPLEMENTATION**

## Objective

Make the M10 expert sandbox usable for a small, guided evaluation by invited
manufacturing specialists. The pilot collects usability and domain-feedback
signals; it is not a production deployment or evidence of factory benefit.

## Frozen boundaries

- The pilot uses deterministic demo records and the mock/local provider only.
- Participant codes are pseudonyms. Names, email addresses, employee IDs, and
  other directly identifying information must not be entered.
- Feedback remains a separate annotation and is never manufacturing truth or
  an automatic post-training example.
- `task_elapsed_seconds` means browser time from pressing **Run investigation**
  until submitting feedback. It must not be described as labor savings.
- Reset applies only to the explicitly named dedicated pilot Compose project.
  It exports feedback before removing that project's database volume.
- Track A and Track B remain mandatory, independent gates.
- No MES, ERP, QMS, WMS, ticketing, or PLC write/execute authority is added.

## Delivery

- **M10.5.0:** freeze this contract.
- **M10.5.1:** dedicated start, stop, export, and guarded reset commands.
- **M10.5.2:** three fixed guided tasks and facilitator instructions.
- **M10.5.3:** pseudonymous scenario-linked feedback and explicitly bounded
  browser-elapsed metrics export.

## Acceptance

Formatting, Clippy, unit/PostgreSQL tests, the end-to-end HTTP demo, M9 formal
regression, Track A, Track B, export validation, and the no-execution gate must
all pass before M10.5 is recorded as complete.
