## Frozen contract

The binding contract is [M7 trusted identity and authorization contract](m7-auth-contract.md).
It defines:

- explicit `dev_headers` and `oidc` authentication modes with a fail-closed
  startup matrix;
- signed JWT access-token validation, OIDC issuer/audience checks, bounded JWKS
  refresh, key rotation, and secret-redaction requirements;
- authoritative local mappings from `(issuer, subject)` to internal users,
  tenant memberships, roles, factory scopes, and capabilities;
- a single `AuthenticatedPrincipal` shared by HTTP authorization and derived
  Agent tool contexts;
- tenant/factory scope-selection rules that cannot grant access by themselves;
- role-to-capability bundles for viewer, production analyst, supervisor, and
  admin;
- endpoint, self/tenant Agent-run, resource-hiding, rate-limit, and audit
  semantics;
- planned identity persistence boundaries and historical-run migration
  constraints;
- 26 mandatory security and regression cases; and
- explicit exclusions for writes, approvals, SOP compilation, event sourcing,
  CD, and production hosting.
