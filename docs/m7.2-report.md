## Implemented boundary

M7.2 enforces the capability matrix frozen by M7.0:

- every MES read endpoint requires `read:mes` after authentication and local
  membership/factory resolution;
- Agent-run creation requires both `run:agent` and `read:mes`, plus the
  selected factory scope;
- Agent-run and tool-call reads require either `read:agent_runs:self` for a
  run owned by the authenticated internal user or
  `read:agent_runs:tenant` for another user in the same tenant;
- another user's run is hidden with `resource_not_found` from self-scoped
  callers, while callers with no run-read capability receive the generic
  `authorization_denied` response;
- role names are expanded to their frozen capability bundles, but endpoint and
  tool enforcement checks capability values rather than role strings;
- zero roles grant no capabilities, and an empty factory-scope set grants no
  factory access;
- new authenticated runs use the internal UUID string for ownership, while
  historical development runs remain readable by their matching development
  subject;
- MES Agent tools independently require `read:mes` and use only the
  server-derived tenant/factory context; a model-supplied `factory_id` is
  rejected by the strict tool argument schema; and
- the evaluation-only `read:evaluation_datasets` capability remains absent
  from every ordinary human role.

M7.2 retains repository-level tenant/factory filters below both HTTP and Agent
authorization. A successful HTTP check does not bypass per-tool checks.

## Decision and remaining work

M7.2 passes because authenticated principals now have their locally derived
capabilities enforced at every existing protected HTTP operation, Agent-run
ownership boundary, and MES Agent-tool execution boundary without weakening
repository isolation.

M7 as a whole is **not complete**. M7.3 must complete the audit fields, full
adversarial JWT/JWKS suite, key-rotation behavior, token-redaction validation,
and formal M7 report. M7.2 does not add MES writes, identity administration,
approval flows, SOP compilation, event sourcing, production hosting, or CD.
