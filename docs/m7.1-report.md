# M7.1 trusted-identity report

Status: **PASS**

Recorded on 2026-11-03 after local unit, PostgreSQL integration, Docker
reproduction, and independent GitHub evaluation gates passed.

## Implemented boundary

M7.1 implements the identity foundation frozen by M7.0:

- persistent internal users, exact `(issuer, subject)` external identities,
  active tenant memberships, roles, explicit all-factory grants, and factory
  scopes;
- a deterministic simulator-created `dev-user` identity and factory membership
  without arbitrary header-based auto-provisioning;
- explicit `AUTH_PROVIDER=dev_headers|oidc` selection and refusal of missing,
  unknown, or non-development `dev_headers` configurations;
- signed RS256 JWT access-token validation with required `kid`, issuer,
  audience, `exp`, `sub`, optional `nbf`, bounded future `iat`, token-size,
  clock-skew, and algorithm checks;
- HTTPS OIDC discovery or controlled HTTPS JWKS override, a five-second HTTP
  timeout, a 15-minute key cache, and one bounded unknown-`kid` refresh;
- database-authoritative local identity, tenant, factory, role, and capability
  resolution after cryptographic verification;
- one `AuthenticatedPrincipal` shape for both development and OIDC adapters,
  projected into the server-created `AuthorizedToolContext`;
- fail-closed authentication errors, Bearer challenges on HTTP 401 responses,
  and non-secret authentication readiness metadata.

No private signing key, bearer token, authorization header, or complete JWT
payload is committed, logged, or persisted. RSA private keys used by tests are
generated at test runtime.

## Decision and remaining work

M7.1 passes because trusted identity is now cryptographically verified in OIDC
mode, mapped to locally authoritative authorization data, and represented by a
single principal without weakening repository tenant/factory isolation.

M7 as a whole is **not complete**. M7.2 must enforce the frozen capability
matrix at every HTTP route and Agent tool boundary. M7.3 must add the complete
adversarial authentication suite, key-rotation verification, extended audit
records, and final M7 report. This milestone does not add MES writes, approval
flows, SOP compilation, event sourcing, production hosting, or CD.
