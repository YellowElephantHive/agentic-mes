# M10.5 Guided Pilot Guide

## Before the session

Start the dedicated local sandbox:

```bash
./scripts/start-pilot.sh
```

Open `http://127.0.0.1:8080`. Assign each tester a pseudonymous code such as
`P01`; do not use a name, email address, employee ID, or company identifier.
Tell the tester that all records are deterministic simulation data, Agent
statements are hypotheses, and approvals cannot execute a manufacturing action.

## Fixed tasks

### Task 1 — Line A output drop

Select **Line A · Output drop + overlapping downtime**. Investigate the event,
inspect all four Tool Calls, create and review the disposition, compile and
dry-run the action plan, then submit feedback.

### Task 2 — Line B quality spike

Select **Line B · Quality spike**. Decide whether the available evidence is
sufficient. Use `missing_key_signal` or `over_inference` when appropriate and
state which source you would inspect next.

### Task 3 — Case recovery

Open a Work Queue item, refresh the browser, and recover the case from its URL.
Explain whether the restored evidence and lifecycle status are understandable.

## Facilitator rules

- Do not explain where a button is unless the tester is blocked for two minutes.
- Record observations separately; do not edit the tester's feedback.
- Do not claim that elapsed time measures production benefit. It covers only the
  browser interval from investigation start through feedback submission.
- A missing or inconclusive answer is an acceptable result. Do not coach the
  tester toward a positive rating.

## End of session

Export annotations and aggregate metrics:

```bash
./scripts/export-pilot-feedback.sh
./scripts/stop-pilot.sh
```

The export contains pseudonymous feedback, record identifiers, ratings, and
bounded timing metadata. It excludes database credentials, user identity IDs,
raw source records, and model secrets.

To archive feedback and recreate the deterministic sandbox:

```bash
PILOT_CONFIRM_RESET=RESET ./scripts/reset-pilot.sh
```

Reset removes only the dedicated `agentic-mes-pilot` Compose volume after a
successful export. The normal development project and evaluation datasets are
not targeted.
