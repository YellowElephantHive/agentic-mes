# M9.8 Operator Console

Status: **IMPLEMENTED — VERIFICATION PENDING**

M9.8 turns the verified read-only investigation path into a browser-based
local demo. The interface is embedded in the Rust API binary and adds no Node
runtime, new data authority, proposal transition, action-plan transition, or
execution capability.

## Start the console

Prerequisites are Rust 1.85+ and Docker with Compose.

```bash
./scripts/run-console.sh
```

Open `http://127.0.0.1:8080`. Stop the stack later with:

```bash
docker compose down
```

The launcher applies migrations, repeats the deterministic seed-42 fixture,
builds the API, and verifies readiness. The console uses the fixed Demo
Factory / Line A development scope and clearly labels its local-only mock
provider and safety boundary.

## Implemented in M9.8

- responsive production overview for current and baseline output;
- downtime and quality source summaries;
- bounded production-analyst question input;
- execution of the existing four-call mandatory evidence gate;
- audited Agent answer, evidence count, run identity, and executed Tool Calls;
- explicit hypothesis-versus-causation and no-write messaging; and
- embedded HTML, CSS, and JavaScript served by Axum.

## Intentionally deferred

M9.8 does not provide proposal creation, reviewer identity switching,
action-plan validation/simulation, approval inboxes, or execution controls.
Those human workflow surfaces belong to M9.9. Existing APIs and formal M9
invariants remain authoritative.

## Acceptance gate

M9.8 passes only when the embedded asset route tests, one-command M9.7 HTTP
acceptance flow, formal Rust/M9 suite, Track A, Track B, and aggregate gate all
pass. Browser visual inspection is an additional presentation check, not a
replacement for those deterministic gates.
